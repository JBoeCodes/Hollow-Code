# Repository layout

Part of the agent manual; [AGENTS.md](../../AGENTS.md) is the entry point. For what a file does now, read its module doc (`//!` in Rust, the header comment in TypeScript), then [the module map](../reference/backend-module-map.md#backend-module-map).

Current workspace modules and commands are mapped in [Workspaces and Library](../WORKSPACES.md#navigation-and-implementation).
Parallel chats each append to `workspaces/<id>/log/<session key>.md` (`shared_docs::chat_log_path`, named by `context_compiler::shared_workspace_note`); the shared docs take only workspace-wide changes ([Shared docs](../WORKSPACES.md#shared-docs-while-chats-run-in-parallel)).
Build workspaces may add worktrees (lanes): one turn per worktree ([design](../BUILD_WORKSPACES_MULTI.md)).
